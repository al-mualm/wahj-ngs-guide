AB1 upload + alignment + annotation

SeqStudio / Sanger Smart Analyzer

Upload raw .ab1 Sanger files, trim low-quality ends, align each read against a selected reference, inspect chromatogram evidence, annotate candidate variants, and export clean publication-ready outputs.

Scientific guardrails

Candidate differences are called from sample-level pairwise alignments. Low-quality positions are not presented as confident variants. Clinical annotations are descriptive database summaries only and are not diagnoses.

The core analysis is browser-side. The tool works without sending your AB1 files to a remote server. External annotation lookups are optional and happen only after you choose a reference and run the analysis.

Step 2

Choose the reference

Genomic DNA is the safe default for PCR amplicons because it preserves introns and primer-flanking sequence. Choose cDNA only when the sequenced template was made from RNA. The reference type must match the laboratory material.

This mode first tries GenBank so feature annotations can be used. If only a FASTA record is available, the analysis still runs with limited annotation.

Manual FASTA gives full alignment and variant calling, but feature and database annotations are only available when they can be derived safely.
