Bioinformatics, ACMG and the command line

This companion lecture explains how sequencing data becomes interpretable evidence: raw reads are processed into candidate variants, candidates are evaluated with ACMG/AMP-style logic, and command-line work keeps the analysis traceable and reproducible.

Opening question

The sequencer does not produce a diagnosis

Clinical NGS begins with millions of reads, narrows to thousands of candidate variants, then to a few reviewed findings. The lecture question is what transforms the first box into the last one.

Learning outcome
  • Process the data into reliable, searchable variant calls.
  • Evaluate the evidence with ACMG/AMP germline logic.
  • Document the work in a reproducible command-line record.
Workflow checkpoints

Bioinformatics answers a different question at every stage

The key idea is that FASTQ, BAM/CRAM, VCF, annotation, and report are not interchangeable files. Each one is a checkpoint with its own scientific question.

1

FASTQ

Raw reads plus quality scores.

Question: can I trust the letters?
2

BAM / CRAM

Reads mapped to a reference with alignment metadata.

Question: where did each read come from?
3

VCF

Variant records with genotype and quality fields.

Question: what differs from the reference?
4

Annotation

Gene, transcript, population, and disease context.

Question: what is already known?
5

Report

Findings that can be responsibly communicated.

Question: what is clinically defensible?
Standardization

Why ACMG/AMP guidance was needed

Before the 2015 consensus paper, laboratories often used different words for similar evidence. The joint ACMG/AMP framework standardized terminology and evidence weighting for germline Mendelian variant interpretation.

ACMG

Medical genetics and genomics practice guidance.

AMP

Molecular pathology and diagnostic standards.

CAP

Laboratory quality, pathology standards, and accreditation influence.

ASCO

Somatic oncology guidance later, not the 2015 germline paper.

ClinGen

Ongoing refinement, expert panel specifications, and criteria updates.

Evidence logic

How to read ACMG/AMP evidence codes

PVS, PS, PM, PP, BA, BS, and BP are evidence directions with defined strengths. The number identifies the criterion; it does not rank criteria within the same strength.

Evidence families

Independent directions of evidence

  • Population frequency
  • Variant effect and molecular consequence
  • Functional data
  • Cases and controls
  • De novo status
  • Segregation
  • Allelic phase
  • Phenotype specificity

Common traps

Most errors come from overclaiming evidence

  • Rare does not automatically mean pathogenic.
  • Several in-silico tools usually count once, not as multiple criteria.
  • ClinVar entries must be checked for stars, date, and evidence quality.
  • Not every stop-gain justifies automatic PVS1.
  • A VUS is not a diagnosis and should not be forced into likely pathogenic.
Reproducibility

Why command-line work matters in clinical genomics teaching

Graphical interfaces remain useful, but command-line analysis becomes essential when workflows must be repeatable, traceable, automatable, and suitable for servers or high-performance computing.

Repeatable

Run the same operation across many samples with the same parameters.

Traceable

Save commands, versions, and filters so another person can reconstruct the work.

Automatable

Connect QC, alignment, variant calling, and filtering into one pipeline.

Synthesis

What students should remember from this lecture

A sequencer generates data, not a diagnosis. Bioinformatics organizes that data, classification evaluates the evidence, and the command line makes the path explicit.

Take-home messages

  • FASTQ, BAM/CRAM, and VCF answer different questions.
  • Filtering, prioritization, and classification are separate steps.
  • ACMG/AMP uses five final germline classes.
  • Evidence codes are weighted observations, not conclusions by themselves.
  • Current ClinGen and gene-specific refinements must be checked.
  • The command line supports reproducibility and auditability.
