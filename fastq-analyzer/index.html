Analyze NGS FASTQ reads in the browser and review read counts, GC content, Q20/Q30 percentages, per-cycle quality, base composition, adapter warnings, duplicated reads, and exportable QC summaries.

Local analysis

FASTQ files stay inside this browser session. The page does not upload read files to the website backend.

The analyzer streams each file locally and includes all parsed reads in the QC metrics. Large compressed FASTQ files can take time, so keep this tab open until the run finishes.
